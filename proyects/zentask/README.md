# AI Studio App – Gemini Integration

Aplicación desarrollada con **Google AI Studio** que integra modelos **Gemini** para ejecutar funcionalidades basadas en inteligencia artificial desde una interfaz web.

Este proyecto forma parte de mi portafolio de **vibecoding**, explorando el desarrollo rápido de aplicaciones con IA generativa.

---

## 🚀 Demo

👉 Ver la aplicación en AI Studio:  
https://ai.studio/apps/drive/1VaI9VaJ8zI95Fpu8Zi7pxOE7o-OUymHz

---

## 🧠 ¿Qué hace esta aplicación?

- Consume la API de **Gemini**
- Permite ejecutar prompts desde una interfaz web
- Demuestra un flujo completo:
  - Frontend
  - Configuración de entorno
  - Consumo de modelos de IA

---

## 🛠️ Tecnologías utilizadas

- **Google AI Studio**
- **Gemini API**
- **Node.js**
- **JavaScript**
- **Vite / Web tooling (según configuración exportada)**
